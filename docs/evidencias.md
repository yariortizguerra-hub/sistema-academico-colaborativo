# Lista de evidencias del estudiante

Marca cada evidencia después de obtenerla en la ejecución real.

- [ ] Versión de Git (`git --version`).
- [ ] Configuración de usuario (`git config --global --list`), ocultando datos personales si se comparte públicamente.
- [ ] Repositorio creado en GitHub.
- [ ] Estructura de archivos en el editor.
- [ ] Archivo `.gitignore`.
- [ ] Ramas locales y remotas (`git branch -a`).
- [ ] Historial de commits (`git log --oneline --graph --all`).
- [ ] Issues creados.
- [ ] Pull Requests con revisiones.
- [ ] Evidencia del conflicto y su resolución.
- [ ] Salida real de las pruebas automatizadas.
- [ ] README actualizado.
- [ ] Estado final limpio (`git status`).

No incluir tokens, contraseñas, claves privadas ni información confidencial. Las capturas deben corresponder a la ejecución del estudiante.
