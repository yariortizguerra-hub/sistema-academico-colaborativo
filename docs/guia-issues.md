# Issues sugeridos para iniciar el proyecto

## Issue 1: Crear la estructura inicial
**Criterios:** carpetas `src`, `tests`, `docs`; archivos iniciales; `.gitignore`.

## Issue 2: Implementar registro de estudiantes
**Criterios:** acepta código, nombre y programa; rechaza datos vacíos y códigos duplicados.

## Issue 3: Implementar listado de estudiantes
**Criterios:** lista registros y los ordena por código; informa si no existen registros.

## Issue 4: Añadir pruebas automatizadas
**Criterios:** cubre registro válido, campos vacíos, duplicados y ordenamiento.

## Issue 5: Completar documentación
**Criterios:** README explica requisitos, instalación, ejecución, pruebas y colaboración.

En GitHub, crea cada Issue con título, descripción, responsable y etiquetas. Los números de Issue se asignan automáticamente; no inventes números en el informe.
