# Alcance del proyecto

## Problema
El equipo necesita practicar un flujo ordenado para desarrollar y revisar cambios en un prototipo académico sencillo.

## Alcance incluido
- Registro de estudiantes en memoria.
- Validación de campos obligatorios y códigos duplicados.
- Listado ordenado por código.
- Pruebas automatizadas básicas.
- Trabajo colaborativo mediante Git y GitHub.

## Fuera del alcance
- Base de datos y persistencia.
- Inicio de sesión y roles.
- Matrícula, calificaciones y reportes.
- Despliegue en producción.

## Criterios de aceptación
1. El programa se ejecuta con Python 3.10+.
2. Se puede registrar y listar estudiantes.
3. Se rechazan campos obligatorios vacíos.
4. Se rechazan códigos duplicados.
5. Las pruebas automatizadas pasan.
6. Los cambios colaborativos se integran mediante Pull Requests.
