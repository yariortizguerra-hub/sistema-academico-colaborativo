# Rúbrica de evaluación (0–20 puntos)

| Criterio | Puntaje máximo | Evidencia observable |
|---|---:|---|
| Configuración del entorno y repositorio | 2 | Git configurado y repositorio remoto accesible |
| Estructura del proyecto y `.gitignore` | 2 | Carpetas correctas y exclusiones pertinentes |
| Gestión de ramas y commits | 4 | Ramas publicadas e historial claro |
| Colaboración y Pull Requests | 4 | PR con descripción, revisión y fusión verificable |
| Issues y resolución de conflictos | 3 | Tareas registradas y conflicto resuelto documentadamente |
| Funcionamiento y pruebas | 2 | Aplicación ejecutable y pruebas aprobadas |
| Documentación y evidencias | 3 | README y evidencias suficientes para reproducir el trabajo |
| **Total** | **20** | |

## Niveles de desempeño
- **Destacado:** cumple todos los criterios, demuestra comprensión y presenta evidencias completas.
- **Logrado:** cumple los criterios esenciales con omisiones menores.
- **En proceso:** realiza parte del flujo, pero requiere ayuda o presenta evidencias incompletas.
- **Inicial:** no demuestra el procedimiento o faltan entregables esenciales.

El docente asigna puntos dentro del máximo de cada criterio según las evidencias observadas. No se asignan puntos por acciones que no se hayan verificado.
